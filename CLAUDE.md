# CLAUDE.md

## Commits and pushes (hard rule)

- NEVER commit or push any change without the user's explicit permission for that specific commit or push. This rule has no exceptions.
- Permission to make changes is not permission to commit them, and permission to commit is not permission to push. Ask separately each time.

## Design references

The `design-references/` folder holds reference material for improving the app's design, colour palette and layout.

- Do not open, read, list or search anything in `design-references/` without first asking the user for permission, every time.
